Everything runs locally in this page. No data leaves your browser. Save the JSON (and your logo file) into the cmmc_generator folder, then run the commands on the right.

Generate the Documents

  • Branded SPP: python generate.py spp
  • One policy: python generate.py policy --domain AC
  • All 14 policies: python generate.py policy --all
  • One procedure package: python generate.py procedures --domain IR
  • All procedure packages: python generate.py procedures --all
  • Control mapping matrix (Word and Excel): python generate.py matrix
  • Full branded binder with zip: python generate.py binder
