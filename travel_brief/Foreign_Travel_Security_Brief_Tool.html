    User Guide

    1. Quick Start

    On the Brief Builder tab: pick your organization, enter the traveler's name, set whether they are cleared, choose the purpose and dates, select one or more destinations (hold Ctrl on Windows or Cmd on Mac to select several, including transit stops), then click Generate Brief. The full brief renders below the form — review it, then export.

    2. How the Ratings Work

    Every country carries two independent ratings. The advisory level (Levels 1–4) is the State Department's physical-safety rating. The device tier (T1–T3) is this program's counterintelligence and device-security rating. A country can be safe to walk around in and still hostile to your laptop.

    • T1 · Clean Device Required — Burner List country. Clean loaner laptop/phone in; wiped or retired on return; never reconnects to the corporate network.
    • T2 · Loaner Strongly Recommended — Minimal-data or loaner device; no offline sensitive data; remote access only with strong MFA; re-image before rejoining the network.
    • T3 · Standard Precautions — Corporate device acceptable with encryption, patching, minimal-data profile, and the standard checklist.

    A trip is rated by the worst tier and worst advisory level across all destinations and transits. Checklist items tagged [TIER 1] apply only to Burner List trips; items tagged [TIER ≤ 2] apply to T1 and T2 trips.

    3. Cleared vs. Non-Cleared

    Setting Cleared Personnel = Yes adds the SEAD-3 Reporting Obligations section (pre-travel reporting, suspicious-contact reporting, post-travel debrief) and names the FSO in the brief header. Non-cleared briefs omit SEAD-3 content but keep the safety, embassy, and digital-security material.

    4. Exports

    • Export PDF (print) — opens the browser print dialog with only the brief visible. Choose “Save as PDF”. The filename is pre-set from the traveler and country.
    • Export Word (.doc) — downloads a Word-compatible document you can edit before issuing.
    • Export HTML — downloads a standalone HTML copy of the brief, suitable for email or archive.

    Generate the brief first; the export buttons use the most recently generated brief.

    5. Organizations (Multi-Tenant)

    The Organizations tab lets one FSO (or a security service provider) run briefs for multiple companies. Each organization stores its own name, FSO, 24/7 security contact, IT device-handling contact, classification line, and footer. Click an organization to edit it; the one marked active feeds the Brief Builder. Export Config downloads all organizations as a JSON file; Import Config loads one — use this to move between computers or share a standard setup, since data otherwise lives only in this browser's localStorage.

    6. Country Risk Reference

    The reference tab lists every country in the tool with its advisory snapshot and device tier, plus the Burner List. Advisory levels change — the snapshot is for planning only. Verify the live advisory at travel.state.gov before every departure, and update the snapshot in the file's COUNTRIES data block when levels change (each country is one line; set adv: 1–4 and tier: 1–3).

    7. Record-Keeping Reminders

    • Issue the brief before departure and keep the signed acknowledgment — it serves as the defensive-briefing record.
    • Post-travel debrief is due within five (5) business days of return.
    • Itinerary deviations are reported as they happen, not after return.
